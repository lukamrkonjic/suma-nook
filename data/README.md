# Data

- `tokens.json`: themed Coin identities, display, palette, visitor weight, and reward pool.
- `items.json`: stable item identities and all placement/reward/interaction metadata.
- `beginner_rewards.json`: deterministic opening sequence and expansion pity.
- `tuning.json`: names, timing, caps, grid scale, sale threshold, and save version.
- `audio_events.json`: named sound-event variants.
