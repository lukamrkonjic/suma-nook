# Garden Galaxy special-item inspiration

Status: reference-only planning notes  
Source role: gameplay inspiration for possible future Suma features

## Clean-room boundary

This document records high-level gameplay functions observed in Garden Galaxy.
It is not a Suma implementation specification and does not authorize copying
Garden Galaxy assets, models, names, UI copy, audiovisual presentation,
balancing, progression structure, or code.

Any future Suma feature inspired by these ideas must use original terminology,
visual design, interaction rules, tuning, progression, and implementation.
Nothing below is committed to the roadmap.

## Coverage

- 137 placeable Garden Galaxy definitions have a normal inspection label.
- Those definitions share 98 distinct normal labels.
- Eight secret descriptions cover 24 placeable definitions.
- Variants with the same function are grouped together.

## Possible Suma design directions

The strongest reusable design patterns are:

1. Placeable objects that modify the world presentation without opening a
   settings menu.
2. Habitat objects that make creatures visibly respond to player decoration.
3. Spatial economy objects whose placement changes reward probability,
   visitor density, or routing.
4. Utility objects that turn organization into world-building: coloured
   delivery routes, physical storage, waypoints, and collection points.
5. Playable decorations that create small verbs rather than passive stat
   bonuses.
6. Collection milestones represented by physical keepsakes in the world.

Any Suma exploration should combine these patterns with its own forest
restoration, parcels, Groveheart, traversal, crafting, and creature systems
rather than reproduce the reference game's item families.
